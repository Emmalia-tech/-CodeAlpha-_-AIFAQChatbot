# AI FAQ Chatbot 🤖

Hey! This is my AI FAQ chatbot project that I built during my CodeAlpha internship. It's a conversational chatbot that answers questions about artificial intelligence. Pretty cool, right?

## What It Does

Basically, you can ask it questions about AI, and it answers them. But the fun part? You can **talk to it** instead of typing. Ask a question using your voice, and it'll give you an answer and even read it back to you out loud. It's like having an AI tutor in your browser.

I built it with 30+ FAQ questions about AI topics that people usually ask about. There are also quick suggestion buttons so you don't have to think about what to ask.

## Cool Features

- 💬 **Chat bubbles** — Normal conversation-style interface, nothing fancy but works smoothly
- 🎤 **Talk to it** — Use your microphone to ask questions (speech-to-text)
- 🔊 **Listen to answers** — The bot reads responses aloud (text-to-speech)
- 💡 **Suggested questions** — Click a button to ask pre-made questions quickly
- 🧹 **Clear chat** �� Start fresh anytime
- 📱 **Works on phone too** — Responsive design, so it works everywhere

## Why I Built This

I wanted to learn how to build a chatbot from scratch. Plus, I was curious about the Web Speech API and how voice features work in web apps. It's something I'd never done before, so it was a great learning experience.

## How I Built It

**Tech stack:**
- React (for the UI)
- TypeScript (to catch bugs early)
- Vite (super fast build tool)
- Web Speech API (browser's built-in voice feature)

No fancy APIs or backends — everything runs in your browser!

## How to Use It

1. Go to the [live demo](https://stackblitz.com/edit/vitejs-vite-j2iwadqf)
2. Type a question or click the 🎤 to speak
3. Click a suggested question button if you want quick answers
4. Click 🔊 to hear the answer read aloud
5. Use the clear button to start over

## Want to Run It Locally?

```bash
# Clone it
git clone https://github.com/Emmalia-tech/-CodeAlpha-_-AIFAQChatbot.git
cd -CodeAlpha-_-AIFAQChatbot

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Then open `http://localhost:5173` and you're good to go.
